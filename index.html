    AnchorTerm

    版本 0.1.0 · Windows SSH 终端客户端

    真终端 · 多标签 · 断线恢复工作目录 · 草稿与 Tab 补全

    Shell Integration（OSC 7）

    在远端 shell 安装 OSC 7 可提高工作目录跟踪精度。未安装时，应用通过解析 cd 与失败回滚跟踪目录。详见仓库 docs/shell-integration.md。

    MCP 服务器

    将本机已连接的 SSH 会话暴露给 AI 工具（Cursor / Claude 等）。默认关闭；仅监听 127.0.0.1，需 Bearer token。工具： sessions_list、session_get、session_exec（侧信道）、 session_read_output。JSON-RPC：POST /mcp。

    stdio 模式会启动 anchorterm.exe mcp-stdio，把 JSON-RPC 转到本机 HTTP MCP。 主程序须保持运行且 MCP 已启用。详见 docs/mcp-user-guide.md。
