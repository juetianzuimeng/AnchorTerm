    在远端 shell 安装 OSC 7 可提高工作目录跟踪精度。未安装时，应用通过解析 cd 与失败回滚跟踪目录。详见仓库 docs/shell-integration.md。

    需要凭据

    需要 OpenSSH 客户端

    未找到 ssh.exe。AnchorTerm 的交互终端依赖系统 OpenSSH，请先安装后再连接。

    1. 打开 设置 → 应用 → 可选功能 → 添加功能
    2. 搜索并安装 OpenSSH 客户端
    3. 或以管理员 PowerShell 执行： Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0
    4. 安装完成后重新打开 AnchorTerm，在终端执行 ssh -V 确认
